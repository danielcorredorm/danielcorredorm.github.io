## What I built

- Multiplayer abilities and core gameplay mechanics for the shooter, in C++ and Blueprints.
- Set up the studio's central Unreal Engine technical documentation and repository guidelines.
- Researched and integrated new Unreal Engine features, and guided cross-functional teams on project structure, optimization and debugging of complex multiplayer systems.


## Project status

The game is in Steam Early Access. GAMECAN EU closed for lack of funding, so development did not continue.
