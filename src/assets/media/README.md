# Images per game or project

One folder per page, named after the last part of its address:
`killer-klowns`, `mariachi-legends`, `contenders-arena`, `oh-hel-no`, `combat-demo`.

In each folder:

- `cover.jpg`: shown on the Home page, in the open file of "Featured work" (games only).
- `1.jpg`, `2.jpg`, `3.jpg`, `4.jpg`: the gallery under the video on the page itself.

16:9, ideally 1920×1080. JPG, PNG or WebP. The gallery shows only when the folder has screenshots.
